# GlobalMap

An open-source 3D map library based on Cesium, designed as an alternative to Mars3D.

## Features

- Compositional architecture (no deep inheritance)
- Modular and pluggable design
- Full TypeScript support
- ESM only

## Packages

- `@globalmap/core` - Core map library
- `@globalmap/example` - Vue3 example demos
- `@globalmap/docs` - Documentation
- `@globalmap/shared` - Shared utilities
